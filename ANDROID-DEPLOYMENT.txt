BITCHORD PUBLIC HI-RES FLAC — ANDROID DEPLOYMENT

1. Extract this ZIP on your Android phone.
2. In Chrome, open https://github.com and sign in.
3. Create a NEW PUBLIC repository named bitchord-public-hires-flac.
4. Open the repository, choose Add file > Upload files.
5. Upload the CONTENTS of this folder (server.js, package.json, Dockerfile, .gitignore, .node-version, render.yaml, README.md). Make sure these files are at the repository root, not inside another folder.
6. Commit the upload.
7. Open https://render.com and sign up/sign in.
8. Choose New > Blueprint (if available) and connect the GitHub repository. If Blueprint is not offered, choose New > Web Service, connect the repo, Runtime Node, Build Command `npm install`, Start Command `npm start`, Free plan.
9. Wait for deploy to finish. Copy the public HTTPS URL shown by Render.
10. Test `https://YOUR-SERVICE.onrender.com/manifest.json` and `https://YOUR-SERVICE.onrender.com/health` in Chrome. The first should show JSON and the second should show ok:true.
11. In BitChord: Settings > Sources > Add an addon. Paste the service base URL (or /manifest.json if requested), Test, then Save. Choose Hi-Res FLAC quality.

NOTES
- Do not upload secrets or private files. The project contains no credentials.
- Render free services may sleep after inactivity and take a short time to wake up.
- Free public music sources do not guarantee 24-bit/192 kHz. The addon can only play actual FLAC files found in the catalogue and reports verified source quality.
- The add-on is a starter integration and has not been validated on your specific BitChord installation. If BitChord rejects the manifest, send a screenshot of the error.
